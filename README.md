# FOWYAD

Сайт бренда FOWYAD: оптика и кузовные детали для Opel. Покупка ведёт на поиск бренда на Ozon.

Локально: `npm install`, затем `npm run dev`. Сайт откроется на http://localhost:3000.

Публикация идёт через GitHub Pages. При отправке в `main` workflow собирает статическую версию и выкладывает её. Бесплатный хостинг GitHub Pages работает с открытым репозиторием.
